## 🤖 Agents

### Invoke Agent

Invokes a specific agent by ID to process a message.

| Parameter | Type | Description                         |
| :-------- | :--- | :---------------------------------- |
| `agentId` | Path | The unique identifier of the agent. |

#### Request

`POST` **`/agents/{agentId}/invoke`**

```json
{
	"message": "who are you?"
}
```

\<details>
\<summary>Headers\</summary>

```
X-Agent-Key: sk-OlvThjkMzIZ5623mA5duuUs5k9pBsFUO2MbtEy7gYIA
Content-Type: application/json
```

\</details>

#### Response

The response is expected to be the output generated by the invoked agent.

### Create Log Item

Creates a new log item for a job.

#### Request

`POST` **`/jobLogs`**

```json
{
	"jobId": "k170hbfq9mfv85p59x4qrp6a957qkn0p",
	"input": "{}",
	"output": "{}",
	"status": "started",
	"timeSpent": 0,
	"startedAt": "{% faker 'randomDateRecent' %}"
}
```

> **Note:** The `startedAt` value in the example uses an Insomnia templating tag (`{% faker 'randomDateRecent' %}`), which should be replaced with an actual timestamp string (e.g., ISO 8601 format) when making an API call outside of Insomnia.

```
Content-Type: application/json
```

### Update Log Item

Updates an existing log item by its unique ID.

| Parameter   | Type | Description                                      |
| :---------- | :--- | :----------------------------------------------- |
| `logItemId` | Path | The unique identifier of the log item to update. |

#### Request

`PUT` **`/jobLogs/{logItemId}`**

```json
{
	"jobId": "k170hbfq9mfv85p59x4qrp6a957qkn0p",
	"input": "{}",
	"output": "{}",
	"status": "completed",
	"timeSpent": 1200,
	"startedAt": "{% faker 'randomDateRecent' %}"
}
```

> **Note:** The `startedAt` value in the example uses an Insomnia templating tag (`{% faker 'randomDateRecent' %}`), which should be replaced with an actual timestamp string (e.g., ISO 8601 format) when making an API call outside of Insomnia.

```
Content-Type: application/json
```

\</details>
